# 南康白起真相探寻

一部取材于用户提供公开资料的虚构“旧互联网档案恐怖”解密游戏。首页是虚构的“远岸社区”；访客点进一篇旧帖后，会在 437 楼回复中逐渐发现新闻目录、小组转述、贴吧记录、网友日记和匿名调查帖。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 游戏结构

- 页面开头标注“剧情为虚构”。
- 首页是一座可以正常点选版块、热帖和用户中心的虚构旧论坛门户。
- 普通热帖有独立正文和回复，可以作为干扰内容正常阅读。
- 点击《[左岸文字] 长沙的南康，一路走好》后进入 437 楼、3 页的主讨论帖。
- 用户提供的原帖 HTML 保存了第 1—200 楼；这些楼层使用原帖公开显示的用户名、精确时间和正文。201—437 楼为游戏剧情内容，不借用原帖用户名编写新发言。
- 资料入口散布在第 35、63、88、126、173、205 和 437 楼，不再使用并列档案导航。
- 每个站外资料页都有来源楼层和返回原帖的入口。
- 七道题集中在“用户中心 → 找回账号 → 密保验证”，包含选择、数字、日期串和文字输入。
- 密保进度和主帖页码保存在浏览器本地，离开页面查资料后不会丢失。
- 完成密保后会恢复第 438—443 楼，论坛账号和页面状态逐步发生异常。
- 夺舍分支需要玩家在虚构论坛里亲手补全“一路走好”并发表新的悼念帖；该操作只写入浏览器本地游戏状态，不会向任何真实论坛发送内容。
- 第 2、4、6 道密保后插入三份异常回执，选择会保存在本地，改变后续旧帖引文、异常回复和部分结局文本。
- 七道密保后进入判断和处理页面，提供五条可达结局。四条新结局按点击逐段展开，阅读位置可刷新续接。
- 夺舍分支使用轻微合成提示音与缓慢暗场，没有鬼图、突然放大的脸或闪屏；声音可关闭，支持系统“减少动态效果”。
- 新进度存储键为 `yuanan-forum-mystery-v6`，不继承旧版单结局进度，便于从头体验三份新回执。

## 结局路线（剧透）

共同密保答案：只听过名字、了解一点的网友 → `18` → 原账号、原帖日期、楼层与链接 → `050705190615` → `那个人` → `1894` → 后来拿泄露凭据验证传闻的人。

三份回执没有正确答案。选择“这是我的账号”会让最终判断预选为“原主人仍在这里”；否则，选择用申请人补齐会预选“没有原主人”；其余预选为“后来的人”。玩家可在冲突处理页改变判断。

| 结局 | 冲突处理页的判断与操作 |
| --- | --- |
| 一 · 留档 | 选择“后来的人反复登录” → “保留记录，结束调查” |
| 二 · 他还活着 | 选择“原主人仍在这里” → “保留会话，等待本人回复” |
| 三 · 查无此人 | 选择“没有原主人” → “删除这个拼成的身份”；或第一种判断下清除空白身份 |
| 四 · 留在门外 | 第二或第三种判断下断开会话 / 撤回申请；也可在发帖页点击“撤回恢复申请” |
| 五 · 替他留下 | 任意判断 → “这些答案也是我的。继续恢复” → 输入“一路走好” → 正文写完后发表 |

完成后可点击“重选最后的处理方式”，不必重答七题。错误的密保答案不会触发独立结局。

## 发布与撤销

GitHub Pages 从 `main` 分支仓库根目录发布。修改后提交并推送到现有仓库，等待 Pages 部署完成。仓库 Settings → Pages → Build and deployment → Branch 选择 None 并保存，可停止发布而保留代码。需要恢复旧版时，通过 `git revert` 撤销对应提交后推送，避免强制覆盖历史。
