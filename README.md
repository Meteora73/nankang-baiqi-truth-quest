# 南康白起真相探寻

一部取材于用户提供公开资料的虚构“旧互联网档案恐怖”解密游戏。页面模拟千禧年前后的论坛、文学站、网友日记和站内搜索；访客通过七道题逐页恢复时间线。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 游戏说明

- 页面开头标注“剧情为虚构”。
- 游戏里的因果关系、系统对白和最终结局均为虚构。
- 真实泄露密码、私人联系方式和身份信息不会出现在网页中。

## 修改

- 页面结构与文字：`index.html`
- 视觉样式：`styles.css`
- 题目、答案和跳页逻辑：`app.js`
