# 南康白起真相探寻

一部取材于用户提供公开资料的虚构“旧互联网档案恐怖”解密游戏。访客通过六道谜题逐步恢复损坏页面，并解锁一个完全虚构的结局。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 创作与现实边界

- 首页进入前醒目标注“本游戏内容纯属虚构”。
- 谜题取材于资料中的文档结构和时间矛盾，不对现实人物经历作陈述或暗示。
- 游戏里的程序、对白、账号行为、因果关系、恐怖现象与结局全部虚构。
- 不公开疑似真实姓名、联系方式、住址、学籍或真实密码。

## 修改

- 页面结构与文字：`index.html`
- 视觉样式：`styles.css`
- 题目、答案和取材边界：`app.js`
