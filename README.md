# 南康白起真相探寻

一部取材于用户提供公开资料的虚构“旧互联网档案恐怖”解密游戏。首页模拟千禧年前后的综合论坛；访客点进一篇旧帖后，会逐渐发现新闻目录、小组转述、贴吧记录、网友日记和匿名调查帖。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 游戏结构

- 页面开头标注“剧情为虚构”。
- 首页是一座可以正常点选版块、热帖和用户中心的旧论坛门户。
- 点击《[左岸文字] 长沙的南康，一路走好》后，七份档案导航才会出现。
- 资料页可以自由往返；没有保存下来的普通帖子和日记会显示“该内容不存在”。
- 七道题集中在“用户中心 → 找回账号 → 密保验证”，包含选择、数字、日期串和文字输入。
- 密保进度保存在浏览器本地，离开恢复页查资料后不会丢失。

## 页面资料对应

- 第 1 页：天涯 `motss/1/158741` 的楼主存档片段及首日回复。
- 第 2 页：2015 年调查帖中的岳阳网新闻目录检索记录。
- 第 3 页：豆瓣主题 `6498755` 中的“旺仔”匿名转述。
- 第 4 页：贴吧 `p/2290449729` 的账号登录、重置与注销讨论。
- 第 5 页：贴吧 `p/2409083427` 的五条澄清及关联主题回复。
- 第 6 页：年轮网络日记本公开目录及《清晨六点》存档。
- 第 7 页：2015 年晋江闲情调查帖截图恢复内容。

第 6 页另收录天涯 `motss/1/159184` 存档中的 19 篇完整日记。所有目录标题均可点击：有存档的显示全文，只有标题而没有正文的显示“该内容不存在”。
